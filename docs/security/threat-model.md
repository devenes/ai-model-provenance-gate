# Threat Model

## 1. System Assets Under Protection

1. **AI Model Weights and Shards (`.safetensors`):** High-value model parameters susceptible to weight poisoning, backdoor insertion, or silent checkpoint substitution.
2. **Tokenizers and Chat Templates (`tokenizer.json`, `tokenizer_config.json`, `chat_template.jinja`):** Attack vectors for prompt framing manipulation, special-token hijacking, or safety-filter bypass without altering model weights.
3. **PEFT / LoRA Adapters (`adapter_config.json`, `adapter_model.safetensors`):** Fine-tuned delta weights that can completely alter base model behavior or be paired with an incompatible base model.
4. **Behavioral Evaluation Evidence (`llm-release-gate.report/v1`):** Release-gating evaluation reports susceptible to replay (reusing an older `PASS` report for a newer model), substitution, or local JSON tampering.
5. **Release Qualification Attestations (`release-qualification/v1`):** Cryptographic release approvals consumed by deployment pipelines.
6. **Deployment Composition Descriptors (`deployment.yaml`):** Runtime container image references, serving configurations, and active adapter mappings.

## 2. Mitigated Threats (20 Core Controls)

| # | Threat | Attack Scenario | Mitigation in `ai-model-provenance-gate` | Verification Package |
|---|---|---|---|---|
| 1 | **Weight Tampering** | Attacker modifies bytes in `model.safetensors` or a weight shard after evaluation. | Streaming SHA-256 changes `bundle-identity/v1`; OMS component digest check and `release verify` fail closed (`FAIL`). | `internal/digest`, `internal/oms`, `internal/deployment` |
| 2 | **Tokenizer Substitution** | Attacker swaps `tokenizer.json` or `chat_template.jinja` after approval. | All tokenizer and template files are part of `bundle-identity/v1` and OMS subject digests; any modification invalidates `bundle_id` (`FAIL`). | `internal/inventory`, `internal/deployment` |
| 3 | **LoRA Substitution** | Attacker replaces `adapter_model.safetensors` or `adapter_config.json`. | Included in `bundle-identity/v1`, CycloneDX BOM, and OMS subjects; substitution triggers `DEPLOYMENT_ARTIFACT_TAMPERED` (`FAIL`). | `internal/formats/peft`, `internal/deployment` |
| 4 | **Base Model & Adapter Mismatch** | LoRA adapter trained for base model A is deployed on base model B. | `peft.EvaluateRelationship` distinguishes `VERIFIED` (cryptographically checked via `--base-bundle`) from `DECLARED_UNVERIFIED` and `MISMATCH`. | `internal/formats/peft`, `internal/policy` |
| 5 | **Unsafe Pickle Deserialization** | Model bundle contains `.pkl`, `.pt`, `.bin` files with arbitrary Python `reduce` opcodes, or `.safetensors` renamed from a `.pkl` file. | Never deserializes or executes model files; rejects `.pkl`/`.pt`/`.bin` extensions (`ErrUnsupportedFormat`) and inspects `.safetensors` magic bytes for disguised Pickle/ZIP signatures (`ErrDisguisedFormat`). | `internal/formats/safetensors`, `internal/formats/huggingface` |
| 6 | **Malformed Model Metadata** | Truncated `.safetensors` headers, overlapping/out-of-bounds tensor `data_offsets`, or corrupt JSON configs. | Static binary header parser verifies `0 <= begin <= end <= data_bytes`, exact contiguous tensor coverage, and strict JSON syntax. | `internal/formats/safetensors` |
| 7 | **Malicious Symbolic Links** | Bundle contains a symlink pointing to `/etc/shadow` or an external weight file. | `os.Lstat` rejects symbolic links (`ErrSymlinkRejected`) at both the bundle root and all nested entries. | `internal/inventory`, `internal/digest` |
| 8 | **Directory Traversal** | Shard index (`model.safetensors.index.json`) or OMS subject references `../../outside.safetensors`. | `NormalizeAndValidateRelPath` and `InspectIndexFile` reject `..` segments, leading `/`, and backslashes (`ErrInvalidRelativePath`). | `internal/inventory`, `internal/formats/safetensors` |
| 9 | **TOCTOU File Changes During Hashing** | Local process mutates a weight file while `ai-model-provenance` is streaming it. | `digest.StreamFile` verifies `os.SameFile`, exact byte count, and identical `ModTime` across pre-open `Lstat`, `f.Stat()`, and post-read `Lstat`/`f.Stat()` (`ErrConcurrentMutation`). | `internal/digest` |
| 10 | **Path Normalization Collisions** | Bundle contains two files that collide under Unicode NFC vs NFD (macOS APFS vs Linux ext4) or ASCII case folding (`Config.json` vs `config.json`). | `inventory.Build` normalizes paths to NFC and tracks both NFC and lowercase path maps, failing closed on any collision (`ErrPathCollision`). | `internal/inventory` |
| 11 | **Untrusted Signing Keys** | Attacker signs a poisoned model or evaluation report with their own valid Ed25519/ECDSA key. | Cryptographic validity is separated from signer trust; keys not matching `policy.*.trusted_signers` return `UNTRUSTED` (`FAIL`). | `internal/verification`, `internal/policy` |
| 12 | **Forged Attestations** | Attacker modifies the JSON payload inside a DSSE envelope or alters `predicate.bundle.bundle_id` without re-signing. | DSSE PAE signature verification fails (`INVALID`), and subject-to-predicate bundle ID cross-checks reject altered statements. | `internal/verification`, `internal/attestation` |
| 13 | **Unknown Signers** | Signature references a `keyid` not configured in policy. | Explicitly classified as `UNTRUSTED` (`ErrUntrustedSigner`) and rejected under strict policy. | `internal/verification` |
| 14 | **Mutable Runtime Image Tags** | Deployment descriptor specifies `vllm/vllm-openai:latest` instead of an immutable digest. | `policy.IsImmutableOCIRef` requires `@sha256:<64-lowercase-hex>`; mutable tags fail strict policy (`RUNTIME_IMAGE_MUTABLE`). | `internal/policy`, `internal/deployment` |
| 15 | **Evaluation Report Substitution** | Attacker supplies a genuine `PASS` evaluation report from a different model bundle. | Adapter checks `candidate.metadata["model_bundle_id"]` and signed `evaluation-evidence/v1` subject against the inspected `bundle_id` (`MISMATCH` $\rightarrow$ `FAIL`). Unbound reports return `UNBOUND` $\rightarrow$ `BLOCKED`. | `internal/evaluation/llmreleasegate` |
| 16 | **Evaluation Report Tampering** | Attacker edits `"gateStatus": "FAIL"` to `"PASS"` in `report.json`. | Under `require_trusted_evidence: true`, the normalized SHA-256 of `report.json` must match the `report_digest` inside the signed `evaluation-evidence/v1` DSSE attestation (`INVALID_OR_TAMPERED` $\rightarrow$ `FAIL`). | `internal/evaluation/llmreleasegate` |
| 17 | **Unknown Regular Files** | Attacker drops an extra unindexed file into the model directory hoping it will be ignored. | `inventory.Build` never omits unknown regular files (`role: "unknown_file"`), changing `bundle_id` and failing OMS 1:1 subject correspondence (`UNSIGNED_FILE_PRESENT`). | `internal/inventory`, `internal/oms` |
| 18 | **Oversized Metadata & DoS Inputs** | Attacker crafts a `.safetensors` file claiming a 10 GiB JSON header or a 5 GiB `config.json`. | Enforces explicit header and metadata byte limits (`DefaultMaxHeaderBytes = 100 MiB`, `DefaultMaxConfigBytes = 32 MiB`) before allocating buffers. | `internal/formats/safetensors`, `internal/formats/huggingface` |
| 19 | **Sensitive Metadata Leaking into Reports** | `config.json` or report contains an accidental `hf_...`, `sk-...`, `ghp_...`, `AKIA...`, or `PRIVATE KEY` block. | `huggingface.ScanForSecrets` scans both input metadata files and rendered JSON/Markdown reports before writing to disk (`ErrSensitiveMetadataDetected`). | `internal/formats/huggingface`, `internal/report` |
| 20 | **Scanner Coverage Misrepresentation** | User assumes a passing format scan or Safetensors header check means the model's outputs are safe. | Every scanner result and report includes an explicit coverage disclaimer distinguishing serialization safety from behavioral safety. | `internal/scanner`, `internal/report` |
